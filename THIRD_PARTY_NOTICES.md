# Third-party notices

This source tree pins Go dependencies in `go.mod` and `go.sum`. The following notices come from the runtime dependency versions used by the Go gateway and example executor. Keep this file with redistributed binaries.

Claude Code is a separately installed executable under its own terms. CI obtains a pinned test executable from the Anthropic package; no Claude executable or TypeScript SDK implementation is redistributed in this source tree. The Feishu adapter uses the official SDK’s public wire types and independently implements cancellable transport behavior. No cc-connect implementation was copied.
